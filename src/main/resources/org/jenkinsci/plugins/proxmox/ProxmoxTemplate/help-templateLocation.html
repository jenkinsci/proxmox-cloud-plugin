Single source template finds one template on Template Node using its VM ID, a name regular expression, or a tag. If agents may start on another selected node, the template disks and the clone's target storage must be on storage shared with that node.
Matching template on each agent node finds the newest template matching the configured name regular expression or tag separately on each selected Agent Node and clones it locally. Shared storage is not required. Templates may have different VM IDs, but you are responsible for keeping them equivalent.
